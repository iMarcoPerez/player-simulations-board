# Player Simulations Board

Projections, model picks, grades and line movement for NBA, NFL, soccer, tennis, CS2 and NHL.

**Live board:** https://imarcoperez.github.io/player-simulations-board/

This repo holds the board's public data snapshots (`data/`) plus the viewer page (`index.html`). The page reads the JSON files directly — no server. Data is a snapshot, refreshed a few times a day; every section carries its own as-of stamp, and anything marked PRELIM is not final.
